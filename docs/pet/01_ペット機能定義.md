# ペット機能

* クエストに出現する敵を捕獲し、ペットとして所持・育成・呼出できる.
* 所持上限は 1 プレイヤーにつき 3 体とする.
* 同じ種類の敵を重複して所持できる.
* ペットにニックネームは付けられず、元の敵マスタの名前をそのまま表示する.
* ペットのステータスは「元の敵マスタの基本ステータス + 育成による加算分」で決まる.
* ペットのデータは敵マスタ（CSV）への参照と育成加算分のみを DB に保存する.

## 捕獲について

* クエスト戦闘中の行動メニューに「捕獲」を追加する.
* 捕獲は対象の敵 1 体を選んでターン行動として提出し、ターン解決時に成否を判定する.
* すべての敵が捕獲対象となる（ボス階層の敵も含む）.
* 成功率は次の式で決まる: `clamp(基礎率 + (プレイヤーレベル − 敵レベル) × 5, 5, 95) %`
* 基礎率は敵の絶対レベルが高いほど下がる段階テーブルとする.

| 敵レベル | 基礎率 |
| --- | --- |
| 1〜9 | 75% |
| 10〜19 | 60% |
| 20〜39 | 50% |
| 40〜59 | 40% |
| 60〜99 | 30% |
| 100〜199 | 20% |
| 200〜399 | 15% |
| 400〜699 | 10% |
| 700 以上 | 5% |

* 成功率はプレイヤーに事前表示しない.
* 捕獲に成功した敵は戦闘から除外され、経験値・ゴールド・ドロップ報酬の対象外となる.
* 捕獲に失敗した場合は行動を消費するのみとする.
* 所持数が上限 3 体のときは「捕獲」ボタン自体を表示しない.
* 所持数が上限のまま捕獲コマンドを提出した場合は、提出時に 409 で即時拒否する（ターンは消費しない）. ターン解決時の所持数チェックも最終防衛線として行う.
* 同一ターンで対象の敵が先に倒された・捕獲された場合は、攻撃と同様に対象消失として扱う.

## 育成について

* ペット管理ページ（/pets）で育成できる.
* 1 回の育成で 100,000 ゴールドを消費する.
* 1 回の育成で、プレイヤーの素の基本 7 ステータス（最大HP・最大MP・力・守備・知力・運・素早さ）それぞれの 1 %（端数切り捨て）がペットの加算ステータスに加わる.
* 装備ボーナス、および命中・回避・会心・被ダメージ軽減は育成の対象外とする.
* 育成回数に上限は設けない.

## 呼出について

* 呼出はソロクエスト限定の機能とする（マルチでは「呼出」ボタンを表示せず、サーバでも受け付けない）.
* 呼出はターン行動として提出し、そのターンのプレイヤー自身の行動を消費する.
* 呼出すると所持ペット全員（最大 3 体）がまとめて出撃する. ドラクエ8のスカウトのように、プレイヤー側（本人・NPC 味方）は下がって行動しない.
* 出撃したペットは最前列から詰めて並ぶ（前列左 → 前列右 → 中列左 → …）. 並び順はスタンバイ設定したペットを先頭に、残りは捕獲順.
* 呼出したターンを 1 ターン目として 3 ターン戦う. 3 ターン経つか、ペットが全員倒れたら終了し、次のターンからプレイヤー側が元の位置・元の HP のまま戻る.
* ペットは HP を持ち、敵の攻撃対象になる. HP が 0 になったペットは退場する. 出撃中、下がっているプレイヤー側は敵の攻撃を受けない.
* ペットの HP・状態異常は出撃中の 3 ターンの間持ち越す. クエスト外（ペット一覧）には反映しない.
* 行動内容は、元の敵マスタの技からランダムに 1 つ発動する. 技を持たない場合は通常攻撃とする. MP は消費しない.
* ペットの威力計算は既存のダメージ計算式を「敵マスタのステータス + 育成加算分」で適用する.
* 出撃中、プレイヤーは「ペットにまかせる」を押して 1 ターンずつ進める. 行動受付期限を過ぎた場合も自動で「ペットにまかせる」として進める.
* 出撃中にフロアをクリアした場合、残りターンがあれば次のフロアでもペットのまま続ける.
* エンドレスモードでもソロなら使える.
* 呼出はパーティで 1 クエスト 1 回まで.
* クエスト参加時点の所持ペットをスナップショットとして保存し、クエスト中はそれを使用する.
* ペットを所持していない、呼出済み、またはマルチのときは「呼出」ボタンを表示しない.

## ペット管理ページ（/pets）について

* 所持ペットの一覧（元の敵の名前・画像・合計ステータス・育成加算分）を表示する.
* 育成（100,000 ゴールド消費）を実行できる.
* ペットを逃がす（削除）ことができる.
* 呼出時に先頭に並ぶペット（スタンバイ）を 1 体設定できる.

## クエスト行動メニューの変更

* 「捕獲」「呼出」を追加する.
* 「待機」はフロントエンドのボタンのみ非表示にする（`ActionKind.Wait` はサーバ側に残し、自動提出等の既存機能は維持する）.

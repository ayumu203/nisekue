# ペットバトル機能

* ペット管理ページ（/pets）から自分のペット（1〜3体）を使って他プレイヤーのペットと対戦できる.
* 相手プレイヤーはオフラインでもよい（非同期対戦）. 相手のペットはサーバが AI で自動操作する.
* 対戦はレート戦であり、勝敗によってポイントが変動する. 報酬・経験値の付与はない.

## マッチングについて

* 対戦開始時、自分のレートに近い相手を自動選出する.
* 選出優先度: 自レート±200以内 → ±500以内 → 全プレイヤー（段階的拡大）.
* 相手の選出条件: ペットを1体以上所持していること.
* 自身の対戦条件: ペットを1体以上所持していること.
* 対戦終了後1分間はクールダウンが発生し、新たな対戦を開始できない.

## 対戦の進め方

* 対戦開始前のロビーで、自分の所持ペット（1〜3体）を 2×3 の配置グリッドに手動配置する（既存クエストの配置 UI を流用）.
* 相手のペットはサーバが自動配置する（前衛左→前衛右→中衛左→中衛右→後衛左→後衛右の順）.
* 自分と相手のペット体数が異なっても対戦は成立する.
* 戦闘は単一戦（複数階層なし）で、どちらかのペットが全員戦闘不能になった時点で終了する.
* 自分のペットの行動は毎ターン手動で選択する.
* 相手のペットは既存の敵 AI（`QuestEnemyActionPolicy`）が操作する.

## レートシステム

* 各プレイヤーはペットバトル用レートポイントを持つ.
* 初期値は 1000、下限は 0.
* 勝利で +10 ポイント、敗北で −5 ポイント（下限 0 でクランプ）.
* レートポイント・勝利数・敗北数・総対戦数を `player_pet_battle_stats` テーブルで管理する.
* レコードは初回対戦開始時に自動作成する（登録フロー変更なし）.
* 相手への対戦結果通知はしない.

## /pets ページへの追加

* 自分のレートポイント・勝利数・敗北数・総対戦数を表示する.
* 「対戦する」ボタンからペットバトルルームの作成（マッチング→配置→開始）を行う.

# ステージング環境

旧本番環境（Azure App Service + Supabase `Nisekue-Prod`）をステージングとして再利用する。
旧 dev 環境（Azure App Service dev + Supabase `Nisekue`）は廃止した。

## 構成

| | staging | prod |
|---|---|---|
| 起点ブランチ | `main` | `prod` |
| フロントエンド | GitHub Pages (`deploy-frontend-staging.yml`) | Cloudflare Pages |
| バックエンド | Azure App Service（旧 prod の Web App, `deploy-backend-staging.yml`） | Oracle VM (`deploy-backend-vm-prod.yml`) |
| DB | Supabase `Nisekue-Prod`（ソウル, `pfigwkdwtyqchsiljkod`） | Supabase `Nisekue-Prod-Tokyo`（`ycxjbuhqhsupeuqdrcyu`） |
| マイグレーション | `db-migrate-staging.yml` | `db-migrate-prod.yml` |
| GitHub Environment | `staging` | `prod` |

## 初期設定（手作業）

### 1. GitHub Environment `staging` を作る

`Settings > Environments > New environment` で `staging` を作り、次を登録する。

| 種別 | 名前 | 値 |
|---|---|---|
| Secret | `AZURE_WEBAPP_PUBLISH_PROFILE_BACKEND_STAGING` | 旧 prod Web App の発行プロファイル（`prod` の `AZURE_WEBAPP_PUBLISH_PROFILE_BACKEND_PROD` と同じもの。Azure Portal の「発行プロファイルのダウンロード」で再取得できる） |
| Secret | `SUPABASE_DB_CONNECTION_STRING` | `Nisekue-Prod`（ソウル）の Session Pooler 接続文字列 |
| Variable / Secret | `VITE_API_BASE_URL` | 旧 prod Web App の URL |
| Variable / Secret | `VITE_SUPABASE_URL` | `https://pfigwkdwtyqchsiljkod.supabase.co` |
| Variable / Secret | `VITE_SUPABASE_ANON_KEY` | `Nisekue-Prod` の anon / publishable key |
| Secret | `MARKET_CLEANUP_TOKEN` | App Service の `Maintenance__MarketCleanupToken` と同じ値 |

GitHub Pages のデプロイを `staging` から許可するため、`staging` の Deployment branches に `main` を含める。

### 2. 旧 prod Web App の設定を変える

Azure Portal の Web App > 環境変数で次を設定する。

- `ASPNETCORE_ENVIRONMENT=Staging`
  - `appsettings.Staging.json` により CORS 許可先が `https://ayumu203.github.io` になる
- `Cors__AllowedOrigins__*` が設定されていれば削除する（設定ファイルより優先されるため）
- 接続文字列・`Supabase__ProjectUrl` がソウルの `Nisekue-Prod` を向いていることを確認する
- カスタムドメイン（`api.` 系の本番ドメイン）が残っていれば外す

### 3. 後片付け

- GitHub Environment `dev` を削除する
- `prod` Environment の `AZURE_WEBAPP_PUBLISH_PROFILE_BACKEND_PROD` を削除する（Azure 向け本番デプロイは廃止済み）
- Azure の dev 用 Web App が残っていれば削除する
- Supabase の旧 dev プロジェクト `Nisekue`（シンガポール, `pudpklpqhhkozpipsyao`）を削除する
  - Dashboard > Project Settings > General > Delete project

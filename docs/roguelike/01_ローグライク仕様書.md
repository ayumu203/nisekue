# ローグライク仕様

- 本書は概要仕様。**実装時の正本は `docs/roguelike/02_ローグライク詳細仕様書.md`** とする。
- にせくえの各種作成した要素を組み合わせてローグライクを作成する。
- 基本的な流れはアークナイツに類似する。

## 基本的な流れ

1. プレイヤーデータの作成。
   - にせくえ全体でのプレイヤーデータとは別にローグライク用のプレイヤーデータがローグライク開始ごとに作成される。
2. マスの移動。
    - プレイヤーには初手で3つのマスを選択できる。
    - 各マスの先にはそれぞれ選択可能なマスが存在する。
    - ランダムに他のルートに接続するマスが存在する。
    - プレイヤーは接続するマスへ様々な条件を満たすことで移動することができる。
    - イメージは以下のようになる。

    ```md
        stage11 -> stage12 -> stage13
                      ↓
        stage21 -> stage22 -> stage23 -> boss
                                 ↑
        stage31 -> stage32 -> stage33
    ```

3. マスでのイベント。
    - 各マスでは様々なイベントが発生する。
    - 各イベントは後述するが以下のようなものがある。
    - 「啓示(転職)」
    - 「出会い(仲間の獲得)」
    - 「戦闘(クエスト)」
    - 「宿屋(回復)」
    - 「商店(アイテム獲得)」

## クエスト・ボスステージ

- ローグライクは5つの階層と3 * n (n = 3, 4, 5, 5, 7)のステージにより構成される。
- 各階層の最後ではbossとの戦闘が発生する。
- `roguelike_enemy_spawns`
- `roguelike_enemy_spawns` にはボスステージとそれ以外を識別するための行が必要。

## アイテム

- クエストや訓練場で使用するスキルの効果をアイテムを使用することで発揮できる。
- アイテムは一度使用すると、削除される。
- ローグライク中最大20までのアイテムを保持することができる。
- アイテムには`move_id`を持たせてスキルとの共通化を図る。
- アイテムの効果は`move_effect`, `move_master`を参照する。
- 別途`roguelike_item_master`が必要と考えられる。

## イベント

### 啓示(転職)

- にせくえ同様に転職をすることができる。
- 新たにローグライク用の職業を追加する。

### 出会い

- このイベントでは味方NPCを一人パーティへ加えることができる。
- パーティの上限はプレイヤーを含めて5名。
- このイベント中に5名の場合には一人をパーティから除外することで新たなNPCをパーティへ加えることができる。

### 戦闘

- クエストの階層が1つとなったものと同様。
- 戦闘を行い、経験値・Goldを得る。

### 宿屋

- Goldを消費することでパーティのメンバーを回復することができる。
- パーティの合計レベル * 10のGoldを消費することでHPを満タンにすることができる。
- 金額不足時は 所持Gold / 合計レベル * 10 * 100 の割合でHPが回復される。

### 商店

- Goldを消費することでアイテムを購入することができる。

## その他の仕様

- プレイヤーのHPが0となった場合、その時点でゲームオーバーとなる。

# 各種機能に関して

## 用語の定義

- プレイヤー
  - このゲームをプレイするユーザ.
  - 様々な呼び方になることをさけるため、この開発ではプレイヤーという呼称を利用.

- ゴールド
  - 戦闘などで得られる金銭.
  - アイテムの購入やプレイヤー同士の取引で使用する.

- 冒険
  - 他のプレイヤーやNPCとともに複数体の敵キャラクターが出現するステージを攻略する.
  - ステージは複数階層に分かれており、最後の階層にはボスとなる敵キャラクターが出現する.
  - 冒険中は別のページにアクセスしても、冒険のページへ遷移する.

- トレーニングモード
  - 冒険とは異なり1体の敵キャラクターと戦う.
  - 報酬は得られないが短時間で完結し、経験値を得ることができる.

## トレーニングモード

- Issue

```md
- エンドレスバトルの戦闘をパクる.
- 実装しないもの.
    - レベルアップの処理.
    - 複雑な戦闘ロジック(今回はシンプルな殴り合い)
```

### 機能の目的

- レベル上げ.
- 暇つぶし.
- 戦闘回数稼ぎ(ゲーム上の利益はなく、ただの数値)

## 利用条件

- 基本的にはいつでも可能.

### 通常の冒険との違い

- 戦闘が1回で完結.
- 経験値は得られるが、報酬金
- 戦闘でHPが0となっても、所持ゴールドは減らない.

## 対戦相手

- ゲーム側で実装された敵キャラクターの中から1体と戦闘を行う.
- 名前・レベルがプレイヤーには開示されている.
- すべての敵を選択可能.
- レベルの低い順で表示される.
- 最終的にはレベルでソートを可能にする.
- データはサーバ内のCSVで管理?

### 戦闘

- 戦闘は相手を選択し、サーバ側で処理された結果が帰ってくる.
- スキルは冒険実装後に使用可能とするが、現状は1回攻撃とする.
- 物理または魔法のうち、ステータスの高い方の数値を用いてダメージ計算を行う.
- スキル実装後は魔法の連続使用も可能とする.

- 戦闘の流れ

1. プレイヤーが対戦相手を選択する.
2. 選択された対戦相手との戦闘処理をサーバ側で行う.
3. SPEEDに応じて先手・後手を決定する.
4. 先手・後手がそれぞれ1回ずつ攻撃を行う.
5. 先手の攻撃で後手のHPが0になった場合、その時点で戦闘を終了する.
6. 3~5を3回繰り返し, 勝敗にかかわらず、3回目で戦闘が終了する.
7. 戦闘結果をプレイヤーへ表示する.
8. 対戦で減ったHP・MP・状態異常を全回復する.
9. 5秒待機する.
10. この間、対戦相手の選択のみ行えない.
11. 1に戻る.

- 戦闘結果として表示される内容
  - 勝敗
  - 相手と自分の最大HP
  - 相手と自分の戦闘後HP
  - 経験値

### 経験値

- 経験値は戦闘結果・レベル差(レベルの差が小さいほど大)・与ダメージに応じる.

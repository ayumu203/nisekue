# 追加ジョブ

## 2次職

- 鬼武者
    - 必須: 戦士
    - 習得技: 魔神切り(単体に強力な攻撃), 名称未定(自身の防御力を低下させ, 攻撃力を上昇させるバフ)
- ソードマスター
    - 必須: 戦士
    - 習得技: 名称未定(敵一行を攻撃する戦士のものより強力), 名称未定(次の自身のクリティカル率を上げるバフ)
- トリックスター
    - 必須: 盾使い
    - 習得技: 名称未定(ちょうはつ・回避上昇), 名称未定(受けるダメージのn％をカットするバフを付与)
- クルセイダー
    - 必須: 盾使い
    - 習得技: 名称未定(ちょうはつ・防御上昇), 名称未定(受けるダメージのn％をカットするバフを付与)
- 火魔法使い
    - 必須: 魔法使い
    - 習得技: 名称未定(敵一列を攻撃する魔法), 名称未定(自身の知力を上げるバフ)
- 水魔法使い
    - 必須: 魔法使い
    - 習得技: 名称未定(敵一行を攻撃する魔法), 名称未定(自身の知力を上げるバフ)
- 風魔法使い
    - 必須: 魔法使い
    - 習得技: 名称未定(敵全体を攻撃する魔法), 名称未定(自身の知力を上げるバフ)
- 神官
    - 必須: 僧侶
    - 習得技: 名称未定(味方一列を強力に回復), 名称未定(味方1人に継続的な回復状態を付与, トラップの逆)
- 死霊使い
    - 必須: 僧侶
    - 習得技: 名称未定(敵一体を30%の確率でHP0にする, ただしボスには無効), 死霊召喚(自身の筋力+知力のn%で敵を攻撃)
- スナイパー
    - 必須: レンジャー
    - 習得技: 名称未定(敵に毒状態を与える), 名称未定(敵を2.5%の確率でHP0にする, ボスにも有効)
- 罠師
    - 必須: レンジャー
    - 習得技: 名称未定(敵に麻痺状態を与える), 名称未定(敵全体の命中を下げる霧状態を付与)

## 3次職

- グランドウォリアー
    - 必須: 鬼武者, ソードマスター
    - 習得技: 名称未定(敵一列を攻撃する非常に強力な攻撃), 名称未定(自身の攻撃力, 素早さを上昇させるバフ, 鬼武者のバフには倍率で劣る), 名称未定(自身のHPを半分にして攻撃力を大幅に上昇させる)
- グランドガード
    - 必須: ソードマスター, トリックスター
    - 習得技: 名称未定(味方が受けるダメージをすべて自身が受ける), 名称未定(自身の防御力, 知力, 最大HPを上昇するバフ), 名称未定(自身の攻撃力, 素早さを0にして防御, 知力を大幅に上昇させる)
- グランドキャスター
    - 必須: 火魔法使い, 水魔法使い, 風魔法使い
    - 習得技: 名称未定(敵全体を攻撃), 名称未定(自身の知力, 素早さを上昇させる), 名称未定(自身のHPを半分にして知力を大幅上昇させる)
- グランドプリースト
    - 必須: 神官, 死霊使い
    - 習得技: 名称未定(味方全体を回復), 名称未定(味方一人を蘇生), 名称未定(味方全体にn%のダメージカット)
- グランドレンジャー
    - 必須: スナイパー, 罠師
    - 習得技: 名称未定(敵全体に罠を仕掛ける), 名称未定(敵を5%でHP0にする, ボスにも有効)
## 4次職

- 大将軍
    - 必須: グランドウォーリアー, グランドガード
    - 習得技: 名称未定(自身の全ステータスを大幅上昇させる), 名称未定(敵一体に超強力な攻撃)
- 大魔法使い
    - 必須: グランドキャスター, グランドプリースト
    - 習得技: 名称未定(敵全体を攻撃),習得技: 名称未定(味方全体を超回復) 名称未定(味方全体のMPを回復)
- 大盗賊
    - 必須: 戦士, 風魔法使い, グランドレンジャー
    - 習得技: 名称未定(敵を10%でHP0にする), 名称未定(敵全体に30%の確率で麻痺・毒・やけど・霧を付与)
- 大騎士
    - 必須: グランドガード
    - 習得技: ししゅ, てっぺきのかまえ, ぜったいぼうぎょ
## 5次職

転職にはLv60と前提ジョブのマスター、および対応する「証」アイテム（黄金の里でドロップ）が必要。

- 武神
    - 必須: グランドウォリアー
    - 習得技: いっとうりょうだん, しょうぐんのごうれい, おうのしんぱん
- 星界王
    - 必須: グランドキャスター
    - 習得技: だいりゅうせい, ほしのいのり, ダークスター
- 魔盗王
    - 必須: 大盗賊
    - 習得技: 首狩り, かいとうのけむりだま, しのせんこく
- 守護神
    - 必須: 大騎士
    - 習得技: みんなをまもる, 冥王のちょうはつ, 冥府の息吹
    - タンク系の到達点。HPと防御の成長が全職トップ

### 5次職専用装備

各5次職専用の武器・防具を黄金の里（stage 10）とはがねの墓場（stage 8）のドロップに追加。

- 武神: ぶしんのつるぎ / ぶしんの鎧
- 守護神: しゅごしんのやり / しゅごしんの鎧
- 星界王: せいかいおうの大杖 / せいかいおうのローブ
- 魔盗王: まとうおうの双刃 / まとうおうのスーツ

# テンプレート

## 使い方

- テンプレートは「戻ってくる地点（セーブポイント）」。レベルは下げられないので、別の条件で試すときはテンプレートを取り込み直す
- 取り込んだあと、レベル操作・転職で確認したいジョブ・レベルまで進め、ステージの難易度などを確認する

## テンプレートの一覧

| ID | 名前 | 内容 |
| --- | --- | --- |
| `initial` | 作成直後（見習い Lv1） | 作成直後の状態に戻す |
| `master-<Job>` | ◯◯マスター | 作成直後 → 見習いをマスター（かつ Lv5 以上）→ 対象ジョブに転職 → 対象ジョブをマスター |

一次職は、マスタデータのうち「前提ジョブなし・見習い以外」のジョブ（`DebugTemplateService.GetTemplates`）。スプレッドシートでジョブを増減しても追従する。

## 作り方：固定の数値ではなく手順として持つ

固定の数値だと、スプレッドシートで成長値やマスターレベルを変えたときにテンプレートが古いまま残り、バランス調整の確認に使えない。取り込むたびに、その時点のマスタデータで通常のレベルアップ（`Player.LevelUp`）と転職（`Player.ChangeJob`、条件の確認あり）を実行する。

## 取り込みで変わるもの・変わらないもの

`Player.ResetProgress` で作成直後に戻してから手順を実行する。作成直後の値は `PlayerInitialState`（プレイヤー作成と共有）。

| 変わる | 変わらない |
| --- | --- |
| レベル・経験値・ジョブ・職業レベル・基本ステータス・スキル・マスター済みジョブ・ロードマップ解放・転生回数 | 名前・画像・ゴールド・アイテム・装備・ペット・クールダウン・経験値倍率・マップ解放・エンドレス最高到達フロア |

装備は外さない。ジョブに合わない装備を付けたままになることがあるので、必要なら装備画面で付け替える。

## 後回し

- 装備やアイテムまで含めた状態を、固定の JSON で書き出し・取り込みする機能（必要になったら作る）

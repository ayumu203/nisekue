# バランス調整

- バランス調整はプレイヤーのステータスの上昇値・ダメージシミュレーションをもとに行う.

## 技バランス調整ルール

- 職階定義は現行ジョブIDに合わせて以下とする.
- 初級職: id1-6
- 中級職: id7-18
- 上級職: id19-23
- 超上級職: id24-25
- `OniWarrior(id7)` は現行データ上は中級職に含むが、今回の追加技付与対象からは外す.
- 技の MP 消費量は、その技を習得するジョブの習得順に応じて `ResolveRequiredLevel(order, masterLevel)` で必要職Lvを求め、`simulation` 配下の同系統または同等ジョブの `max_mp` を参照して決める.
- `simulation` の CSV は `job_level` が 1, 11, 21, 31... の刻みで並ぶため、必要職Lvと一致しない場合は直近の上位サンプルを参照する.
- `Shogun` は `GrandWarrior` と `GrandGuard` の同等帯、`Archmage` は `GrandCaster` と `GrandPriest` の同等帯、`GreatThief` は `GrandRanger` の同等帯を参照する.
- MP 消費量の目安は以下とする.
- 戦士系攻撃技: 最大MPの約20%
- 盾系ちょうはつ技: 最大MPの約5%
- 盾系攻撃技: 最大MPの約15%
- 魔法使い系: Single 5%, Row/Column 10%, Square 20%, All 25%
- 僧侶系: バフ 10%, 回復 Single 5%, Row/Column 10%, Square 20%, All 25%, 蘇生 25%
- レンジャー系: Single 5%, Row/Column 10%, Square 20%, All 25%
- 威力調整の目安は以下とする.
- 初級職: 単体 1.2-1.5倍, 範囲 0.5-0.75倍
- 中級職: 単体 1.5-2.0倍, 範囲 0.75-0.9倍
- 上級職: 単体 2.0-3.0倍, 範囲 1.0-1.5倍
- 超上級職: 単体 5.0倍以上, 範囲 2.0倍以上
- 即死、挑発、罠、継続回復、ダメージ軽減などの非ダメージ効果は上記威力帯の対象外とし、必要に応じて成功率や付随ダメージのみ個別調整する.
- 今回の追加技付与対象は `SwordMaster` から `GrandWarrior` までの指定職、および `GrandRanger`、`Shogun` とする.
- `WaterMage` と `WindMage` は今回は新技を追加せず、既存2技構成を維持する.
